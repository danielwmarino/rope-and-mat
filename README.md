# The 6-Day Rope & Mat Program

A 12-week strength and conditioning program that needs a jump rope and a mat.
Six sessions a week, 20–30 minutes each.

`index.html` is fully self-contained — no build step, no dependencies. The only
external request is Google Fonts. Open it locally or serve it from any static host.

Progress and benchmark numbers are stored in the browser's `localStorage`, so they
stay on whichever device you use.
